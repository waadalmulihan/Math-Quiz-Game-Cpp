# 🧮 Math Quiz Game (C++)

A console-based math quiz game written in C++ that tests arithmetic skills across multiple difficulty levels and operation types.

---

## 📋 Features

- **Multiple Difficulty Levels** — Easy, Medium, Hard, or Mixed
- **Multiple Operation Types** — Addition, Subtraction, Multiplication, Division, or Mixed
- **Customizable Quiz Length** — Choose between 2 and 10 questions
- **Instant Feedback** — Green screen for correct answers, red screen + alert sound for wrong ones
- **Final Score Summary** — Pass/Fail result with full breakdown at the end
- **Replay Option** — Play again without restarting the program

---

## 🎮 How to Play

1. Run the program
2. Enter how many questions you want **(2–10)**
3. Choose a difficulty level:
   - `1` Easy (numbers 1–10)
   - `2` Medium (numbers 10–50)
   - `3` Hard (numbers 50–100)
   - `4` Mix (random difficulty per question)
4. Choose an operation type:
   - `1` Addition `+`
   - `2` Subtraction `-`
   - `3` Multiplication `x`
   - `4` Division `/`
   - `5` Mix (random operation per question)
5. Answer each question as it appears
6. View your final results and choose to play again

---

## 🏆 Pass / Fail Condition

You **pass** if your correct answers are **≥** your wrong answers.
