🧮 Math Quiz Game (C++)

A simple console-based Math Quiz Game built using C++. The program generates random math questions based on selected difficulty and operation type, evaluates user answers, and displays final results.

📌 Features
Choose number of questions (1–10)
Select difficulty level:
Easy
Medium
Hard
Mixed
Select operation type:
Addition (+)
Subtraction (-)
Multiplication (×)
Division (÷)
Mixed operations
Randomly generated questions
Instant feedback (Correct / Wrong)
Colored terminal output:
🟢 Green = Correct answer
🔴 Red = Wrong answer
Final score summary (Pass / Fail)
Option to replay the game
🎮 How the Game Works
The user selects:
Number of questions
Difficulty level
Operation type
The program generates random math questions.
The user answers each question.
The system:
Checks the answer
Shows correct answer if wrong
Tracks score
At the end, results are displayed:
Number of correct answers
Number of wrong answers
Final status (PASS / FAIL)
